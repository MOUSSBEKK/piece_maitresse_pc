# Pièce Maîtresse — version PC

Le FPS aux pièces qui ricochent : lance tes pièces, vises-en une et tire, la balle ricoche sur toutes les autres avant de frapper sa cible.

## ⬇️ Télécharger

**[PieceMaitresse-Windows.zip](https://github.com/MOUSSBEKK/piece_maitresse_pc/releases/latest/download/PieceMaitresse-Windows.zip)** · ou la page **https://piece-maitresse.onrender.com/telecharger**

1. Clic droit sur le zip → **Extraire tout…**
2. Lance **PieceMaitresse.exe** dans le dossier « Piece Maitresse ».
3. Si Windows affiche « Windows a protégé votre ordinateur » : **Informations complémentaires** → **Exécuter quand même**.

## Jouer en ligne
Menu **Multi** : connexion automatique au serveur en ligne. Crée un salon, choisis le mode et la carte, envoie le code à tes amis.

## Configuration
Windows 10 ou 11 (64 bits), carte graphique DirectX 12, clavier et souris.

Version navigateur : https://piece-maitresse.onrender.com
